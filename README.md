# Myntra Clone

A modern, responsive Myntra-inspired e-commerce website built using HTML, CSS and JavaScript.

##  Live Website

https://anshvaishy99.github.io/myntra-clone/

##  Repository

https://github.com/anshvaishy99/myntra-clone

##  Features

- Responsive Myntra-inspired design
- Modern navigation bar
- Hero section
- Product listing
- Product search
- Category filtering
- Product sorting
- Quick View
- Size selection
- Quantity selection
- Add to Bag
- Wishlist
- Shopping Bag
- Coupon system
- Checkout
- Login
- Create Account
- User Profile
- My Orders
- Logout
- Order confirmation
- LocalStorage support
- Loading animation
- Toast notifications
- Mobile responsive navigation

## 🔐 User Authentication

Users can:

- Create an account
- Login
- View their profile
- View personal information
- View orders
- Access wishlist
- Access shopping bag
- Logout

Authentication is implemented using browser LocalStorage for this frontend project.
